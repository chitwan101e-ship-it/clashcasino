Where to find keno on Orion Stars

Orion Stars groups keno with table games. Fish tables, slots, and Links each have a separate place in its game lineup.

Look under Table Games

If you’re looking for keno, start with Table Games. Keno follows a number draw: you select numbers and then see which ones appear. The name of the category can be easy to miss if you’re used to seeing a separate Keno button in a Juwa lobby.

Fish, slots, and Links

The Fish Games section ranges from traditional aquatic targets to alien-themed games. Wolf Strike appears in the artwork for Slot Games. Links has its own listing alongside slots, so anyone looking for Orion’s fire-link variations has a specific category to check.

Joining a friend’s private table

Orion’s FAQ describes two different roles at a private table. The first player takes a seat and receives a table password. A friend can then sit down and enter the password supplied by the host. The code is for that table. It’s separate from either player’s account login.

A quick way to tell which screen you have open

A table password prompt belongs to the private-table flow. A board of numbers belongs to keno. If you arrived hoping to follow a number draw and landed at the password prompt instead, return to the game categories and look for keno in Table Games. For a visual example from another platform, look for the purple buffalo and the word Keno on the Juwa cover.

Keno beside the other categories

On Orion Stars, keno is filed with Table Games rather than under its own Keno button. Fish Games is the moving-target section, and it includes both aquatic and alien themes. Slot Games is where Wolf Strike appears in the artwork. Links is a separate listing for the fire-link style games, so it is not the same screen as slots or keno.

That menu is different from Juwa, where Buffalo Keno, Hexa Keno, and Superball Keno are labeled keno on the cover. If you are looking for a number draw, stay in Table Games. A table password belongs to a private table and is not a keno board or your Clash Casino login. The keno comparison shows what a number board looks like on Juwa.
